## Что такое FreeModel

FreeModel это API relay для разработчиков и пользователей AI-инструментов. Это не просто веб-чат. Здесь важны маршруты моделей, баланс, rate limits, совместимость с клиентами и понятное поведение API.

По предоставленной информации FreeModel поддерживает два формата подключения:

- Claude API format для Claude Code, Cline и Anthropic SDK
- OpenAI-compatible API для Cursor, ChatBox, OpenAI SDK, ChatGPT SDK и похожих клиентов

Если вы уже умеете указывать base URL, API key и model name, проверить FreeModel несложно. Если нужен только обычный чат в браузере, этот сервис может быть избыточным.

## Цена: credits и monthly plans это разные вещи

У FreeModel есть два разных понятия:

- API credits это расходуемый баланс.
- Monthly plans это уровни rate limit.

Если не хватает баланса, нужно пополнять credits. Если упёрлись в rate limit, нужно повышать план. Пополнение баланса само по себе не увеличивает rate-limit window, а месячный план не превращается в такой же объём расходуемых денег.

## Какие API поддерживаются

FreeModel упоминает два привычных API: `/v1/chat/completions` и `/v1/responses`.

### /v1/chat/completions

`/v1/chat/completions` это классический stateless chat API. В каждом запросе нужно передавать историю сообщений заново.

Обычно это лучший первый вариант, потому что его поддерживают многие клиенты, SDK, скрипты и прокси.

Подходит для:

- старых OpenAI SDK проектов
- ChatBox и похожих desktop-клиентов
- простых скриптов
- API gateway, где важнее совместимость

### /v1/responses

`/v1/responses` это более новый Responses API. Он может поддерживать stateful multi-turn flows через `previous_response_id` и более подробные streaming events.

Используйте его, если клиент уже поддерживает Responses API и вам нужен более современный формат для agent workflows. Для простой совместимости сначала лучше проверить chat completions.

## Как подключить FreeModel к Claude Code и Cline

FreeModel предоставляет Claude API format, поэтому его можно использовать с Claude Code, Cline и Anthropic SDK workflows.

Основные параметры:

- API base URL: `https://api.freemodel.dev`
- API key: создать в панели FreeModel
- Model name: копировать из актуального списка моделей в панели

Если инструмент позволяет указать custom Anthropic base URL, поставьте endpoint FreeModel и добавьте API key. Названия моделей лучше не угадывать. Копируйте их из dashboard.

В FAQ есть важный момент: если workflow использует fan-out или sub-agents, orchestrator может назначать разные модели для подзадач. Выбранная модель может работать как main agent, а sub-tasks могут запускаться на других моделях. Это ожидаемое поведение во многих agent workflows, а не обязательно ошибка FreeModel.

## OpenAI-compatible клиенты

Cursor, ChatBox, OpenAI SDK проекты и ChatGPT SDK style инструменты обычно требуют только custom base URL и API key.

Типовая настройка выглядит так:

```text
Base URL: https://api.freemodel.dev
API Key: создать в панели FreeModel
Endpoint: /v1/chat/completions или /v1/responses
Model: gpt-5.5, Claude Fable 5 или другая модель из dashboard
```

Если клиент поддерживает только классический OpenAI Chat Completions, используйте `/v1/chat/completions`. Если есть поддержка Responses API, проверьте `/v1/responses` со streaming и multi-turn context.

## Пример настройки Hermes Agent

Для Hermes Agent provider FreeModel может выглядеть так:

```toml
model_provider = "freemodel"
model = "gpt-5.5"
model_reasoning_effort = "xhigh"
disable_response_storage = true
preferred_auth_method = "apikey"

[model_providers.freemodel]
name = "freemodel"
base_url = "https://api.freemodel.dev"
wire_api = "responses"
```

Здесь важно `wire_api = "responses"`, потому что Hermes будет использовать Responses API вместо обычного chat completions. API key храните в локальной конфигурации секретов. Не вставляйте ключ в публичный репозиторий или статью.

## Ошибка 413 Payload Too Large

Если вы получили `413 Payload Too Large`, тело запроса слишком большое.

Указанные лимиты:

| Tier | Лимит request body |
|---|---:|
| Tier 0 | 3MB |
| Tier 1+ | 5MB |

Что помогает:

- Держать media files меньше 1MB, если возможно.
- Ссылаться на локальные файлы путём, а не встраивать media прямо в request body.
- Делить большой контекст на несколько запросов.
- Не отправлять повторно огромные логи, скриншоты и полный дамп проекта.

Agent-инструменты быстро накапливают большой контекст. Если Claude Code или Cline начинает падать с 413, сначала проверьте размер запроса, а не только выбранную модель.

## Ошибка 403 ip_account_conflict

Эта ошибка означает, что текущий IP уже связан с другим бесплатным аккаунтом:

```text
403 permission_error: ip_account_conflict
This IP is already linked to another free account.
Only one free account is allowed per IP address.
```

FreeModel разрешает только один бесплатный аккаунт на IP, чтобы уменьшить abuse.

Нормальные варианты решения:

- Перейти на платный план. Paid plans не имеют такого же ограничения free account per IP.
- Использовать свою мобильную сеть или другой легитимный network, если вы попали под shared IP.
- Использовать чистую сеть для настройки своего аккаунта, а не для массового создания free accounts.

Для долгой работы стабильный платный аккаунт лучше, чем постоянная борьба с ограничениями бесплатной регистрации.

## Почему Claude замедляется после нескольких задач

Claude Code и похожие agent-инструменты могут замедляться после нескольких больших задач, потому что session context постоянно растёт. Каждое сообщение, tool call, фрагмент файла и лог увеличивает контекст, который модель обрабатывает при каждом ответе.

Решение простое: начать новую сессию с чистым контекстом. Один session лучше держать под одну задачу. Закончили задачу, очистили разговор и начали новый.
