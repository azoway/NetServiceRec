## Что такое AgentRouter

AgentRouter — это единый AI API-реляй. Он не продаёт собственные модели, а агрегирует нескольких провайдеров — OpenAI, Anthropic, DeepSeek, Zhipu AI и других — за одним OpenAI-совместимым эндпоинтом. Вам нужны только:

- Один API-ключ
- Один base URL
- Имя модели

Этого достаточно, чтобы вызывать разные модели из любого совместимого клиента. Архитектура вдохновлена OpenRouter, но работает на некоммерческой основе: без комиссий платформы, без подписок, без минимальных платежей.

## Акция 1: частое пополнение квоты

Эта акция targeting пользователей, которые недавно были стабильно активны и у которых заканчивается квота. Платформа автоматически добавляет дополнительные кредиты — заявка не нужна. Уведомления приходят в QQ-группе или Discord-сообществе после распределения.

Главное: пока вы поддерживаете реальное использование, квота будет часто пополняться в течение акции. Если вы активно программируете, беспокоиться о внезапной нехватке кредитов не нужно.

Смысл механизма понятен — ресурсы получают те, кто реально их использует, а не аккаунты, которые лежат без дела. Если вы зарегистрируетесь и ничего не делаете, пополнения вряд ли придут.

## Акция 2: реферальный буст $100 → $150

Во время акции за каждого успешно приглашённого друга:

Чем больше приглашений — тем больше奖励. По сравнению с обычной наградой $100, эта акция добавляет $50 за каждый реферал.

## Формат API

AgentRouter использует OpenAI-совместимый формат API. Это значит, что большинство AI-клиентов с поддержкой кастомного base URL могут подключиться напрямую.

Основные эндпоинты:

- `/v1/chat/completions`: классический stateless chat API, лучшая совместимость
- Аутентификация: Bearer token (API-ключ)

Если вы уже используете OpenAI SDK, ChatBox, Cursor или другие инструменты с поддержкой кастомного API-адреса, переключение на AgentRouter потребует минимум усилий.

## Советы по использованию квоты

Бесплатные кредиты предназначены для реального тестирования и повседневных задач разработки. Не подходят для:

- Запуска дорогих моделей на бессмысленные разговоры
- Отправки огромного контекста в одном запросе, чтобы сжечь все кредиты
- Ожидания пополнения при бездействии

Выбирайте модели по сложности задачи. Для обычных вопросов и простого кода используйте более дешёвые модели. Claude Opus 5 или GPT-5.6 оставляйте для сложных правок кода, анализа длинного контекста и сложных рассуждений.

Помимо акций и реферальных наград, AgentRouter также предлагает функцию ежедневного чекина. Каждый успешный ежедневный чекин автоматически добавляет $25 кредитов на ваш аккаунт. Эти кредиты можно использовать для вызова любой модели на платформе.

## FAQ

### Сколько кредитов даёт ежедневный чекин?

Каждый успешный чекин добавляет $25 кредитов, зачисляются автоматически и доступны для всех моделей на платформе. Кнопка чекина на главной странице панели, один раз в день.

### Сколько кредитов даёт AgentRouter при регистрации?

Стандартный регистрационный бонус — $100-$200 в зависимости от текущей акции. Регистрация по реферальной ссылке может добавить дополнительные кредиты. Точная сумма зависит от панели на момент регистрации.

### Как работают $150 за реферал и $50 для друга?

Во время акции за каждого успешно приглашённого друга вы получаете $150 кредитов, а друг — $50. После окончания акции реферальная награда возвращается к $100.

### Пополнение квоты автоматическое?

Да, заявка не нужна. Платформа добавляет кредиты на основе активности и объявляет о распределении в QQ-группе или Discord-сообществе.

### AgentRouter берёт комиссию платформы?

Нет. AgentRouter — некоммерческий шлюз без комиссий, подписок и минимальных платежей. Вы платите только за фактическое использование моделей, списываемое с баланса кредитов.

### Поддерживает ли Claude Code?

Да. AgentRouter совместим с OpenAI API, поэтому Claude Code, Cline, Cursor, Roo Code и аналогичные инструменты могут подключиться. Конкретные инструкции по настройке смотрите в документации панели.

### Что делать, когда кредиты закончатся?

Можно пополнить баланс для продолжения использования или дождаться частого пополнения квоты во время акции. Если вы поддерживаете реальную активность, пополнения будут частыми в течение акции.
